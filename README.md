# Simple Calculator Using MATLAB

## About the Project
This is a simple graphical user interface (GUI) calculator developed using MATLAB App Designer.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Power calculation
- Trigonometric operations: Sine, Cosine, and Tangent

## Technology Used
- MATLAB
- MATLAB App Designer

## How to Run
1. Download `app_CALCULATOR.mlapp` from this repository.
2. Open the file in MATLAB App Designer.
3. Run the app and enter the required numbers.
4. Click the desired operation button to calculate the result.
